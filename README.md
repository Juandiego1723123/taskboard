# TaskBoard (version inicial)

Primera version / scaffold del proyecto TaskBoard: un tablero de tareas estilo Kanban construido con HTML, CSS y JavaScript puro. Ver tambien [taskboard1](https://github.com/Juandiego1723123/taskboard1), version posterior del mismo proyecto con estructura de archivos simplificada.

## Estructura

```
taskboard/
├── css/
├── js/
│   └── script.js
└── index.html
```

## Stack

- HTML
- CSS
- JavaScript (vanilla)

## Como correrlo

Es un proyecto estatico sin dependencias: abre `index.html` en el navegador.
